# Java and Python activity icons

Java Activity uses the Java cup and steam symbol from the Devicon project:
https://github.com/devicons/devicon/blob/master/icons/java/java-original.svg

Devicon's MIT license is retained in java-icon-license.txt and distributed in frontend/public/activity-icons/java-icon-license.txt.

Python Invoke uses the Python Software Foundation's official two-snakes logo, without a wordmark:
https://www.python.org/community/logos/
https://s3.dualstack.us-east-2.amazonaws.com/pythondotorg-assets/media/files/python-logo-only.svg

Language marks identify the supported runtime; they do not imply vendor endorsement. The bundled SVGs are in frontend/src/assets/activity-icons, with public compatibility copies in frontend/public/activity-icons. The common icon loader supplies the same artwork to the canvas, palette and picker.
