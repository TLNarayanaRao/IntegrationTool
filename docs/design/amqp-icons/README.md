# AMQP icon proposal

The original four badge-based SVG designs were rejected. They have not replaced production assets or activity references.

The orange broker contains queued messages. Operation badges distinguish Receive (cyan inbound arrow), Get (purple lookup), Send (green outbound arrow), and Dead Letter (red warning). review.html compares activity sizes on dark and light backgrounds; review.png is the rendered preview.

The user approved revision 2 in revision-2/. Its four icons now replace the production AMQP SVGs in frontend/public/activity-icons/ and appear in the activity palette and canvas using the existing activity references. These icons use queue structures, message envelopes, explicit producer/consumer arrows, single-message extraction, and a quarantine queue for dead letters. See revision-2/review.html or revision-2/review.png for dark and light previews at activity sizes.
